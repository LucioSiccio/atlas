A complete, production-ready extension module for Atlas that implements:

## What Each File Does

### Core Implementation (3 files, ~810 lines)

1. **q_kernel.py**
   - Implements q-exponential: `[1 - (1-q)||d||²]^(1/(q-1))`
   - Heavy-tailed kernel for rare outcome discovery
   - Fully compatible with GPyTorch infrastructure

2. **andrews_transformer.py**
   - Maps categorical indices to q-binomial features
   - Uses q-Pascal recurrence for numerical stability
   - O(1) lookup after one-time O(max_n²) table build
   - **Solves the scaling problem** (rmacknight99's issue)

3. **q_gaussian_process.py**
   - Integrates kernel + transformer
   - BoTorch-compatible ExactGP
   - Drop-in replacement for SingleTaskGP

### Testing & Validation (2 files, ~750 lines)

4. **tests/test_qseries_atlas.py**
   - AndrewsTransformer validation
   - QGaussianKernel properties (symmetry, positivity, heavy tails)
   - QGaussianProcess behavior
   - Atlas workflow integration
   - A/B comparison tests

5. **examples.py**
   - Example 1: 2D Branin optimization
   - Example 2: Categorical similarity via partitions
   - Example 3: Scale invariance vs standard normalization
   - Example 4: Black swan discovery with heavy tails

## How It Solves Key Issues

### 1. Scaling Problem (genetic_optimizer.py Issue)
```
Before: Temperature (100-200) treated as 1000x more important than Concentration (0.001-0.1)
After:  AndrewsTransformer projects both to q-manifold → structurally comparable
```

### 2. Missing Rare Outcomes
```
Before: Standard Gaussian dismisses 0.1% yields as noise
After:  q-Gaussian heavy tails maintain search weight where breakthroughs happen
```

### 3. Categorical Similarity
```
Before: Hamming distance: Ethanol vs Methanol = 100% different (0 or 1)
After:  q-binomial coefficients: Chemically similar catalysts map to similar features
```

## Key Design Decision: Approach 3 (Hybrid)

✅ **Non-invasive**: Doesn't touch Atlas core code
✅ **Opt-in**: Use only where beneficial  
✅ **Compatible**: Works with existing BoTorch/GPyTorch
✅ **Extensible**: Easy to contribute improvements
✅ **Testable**: Can validate independently

## Usage Pattern

```python
from qseries_atlas import QGaussianProcess
from gpytorch.likelihoods import GaussianLikelihood

# Your data
train_x = torch.from_numpy(params).double()
train_y = torch.from_numpy(values).double()

# Build q-Gaussian model
likelihood = GaussianLikelihood()
model = QGaussianProcess(train_x, train_y, likelihood, q=1.1)

# Make predictions (exactly like standard GP)
test_x = ...
preds = model(test_x)
```
